# Palette masters

A TypeScript, browser-based art explorer and color-to-UI-theme prototype. Search Wikimedia, browse seven curated art groups, select a painting, extract up to 5 colors from its **actual image pixels**, and apply the palette to three live CSS-variable templates: the SaaS landing page, editorial magazine, and retro poster from `references/living_palette_reference.html`.

**Start here:** [PROJECT_HANDOFF.md](docs/PROJECT_HANDOFF.md) — complete requirements, architecture, technical approaches, image/CSP history, status and continuation plan.

## Run on your laptop

Prerequisites: **Node.js 20.19+ or 22.12+**, npm, a modern Chrome/Firefox/Edge browser, and internet access for remote Wikimedia resources. No API key is required. Optional Python only for the Playwright regression test.

```bash
# Open a terminal in this folder
npm install
npm run dev
```

Visit **http://127.0.0.1:8080/**. To stop the server, press Ctrl+C. On Windows, use PowerShell or Terminal for the same commands.

Development uses Vite with automatic reloads. For production, run `npm run build` and deploy `dist/`. Use `npm run preview` to check that build locally (stop the dev server first). The build now emits HTML and bundled assets rather than a standalone HTML file.

### Deploy to GitHub Pages

In the GitHub repository, open **Settings → Pages → Build and deployment** and
set **Source** to **GitHub Actions**. Merge `.github/workflows/deploy-pages.yml`
into `master`. Every push to `master` (including merged pull requests) then
installs dependencies with `npm ci`, builds the app, and publishes `dist/`.
You can also run the workflow manually from the Actions tab on `master`.

Vite uses relative asset URLs (`base: './'`), so the build supports the repository's
GitHub Pages subpath. The deployment URL appears in the workflow's `github-pages`
environment. No personal access token is required.

### If thumbnails are absent

The distributed source **does not include real artwork image bytes**. The featured gallery uses remote Wikimedia URLs by default; these may be blocked or out of date. On a laptop with internet, cache the pinned Commons images into the app bundle:

```bash
npm run cache:art
npm run dev
```

Then reload **http://127.0.0.1:8080/**. The command attempts the 20 pinned artwork candidates using the Commons API and writes `assets-report.json`. Not all 20 are guaranteed to be available, downloadable or licensed for your intended use. Five additional modern featured works do not have pinned downloadable source files. The cache operation may fail if Wikimedia denies requests; read its console output and the troubleshooting document.

## Template colors

All six base CSS variables (`--color-bg`, `--color-surface`, `--color-text`, `--color-accent`, `--color-secondary`, `--color-tertiary`) map directly to extracted colors, with no light/dark tinting of surfaces. Five-color mode shares the secondary color with tertiary, as in the reference. Images with fewer distinct colors reuse available colors and report their actual count.

Use **Shuffle roles** or the role dropdown beneath each palette swatch. Manual reassignment swaps roles so colors are not dropped; neither operation changes extracted colors. A new extraction resets the mapping to strict dominance, followed by validated dominance-aware fallback when needed. Reset to automatic restores that policy after manual changes. Swatch percentages and ranks describe represented area; display sorting does not change role assignments. Changing the method automatically extracts a new palette. The UI uses five colors; the pipeline retains its configurable five/six-color count parameter. All six current extraction presets are deterministic, verified by repeated-run tests.

Contrast-safe main, surface, accent, secondary, tertiary, and muted foregrounds are calculated independently from the assigned text color. These are separate CSS tokens; base role values and raw `--palette-*` values remain sampled colors. Foreground pairs meet at least 4.5:1, including after shuffle or manual assignment. The contrast badge reports their minimum ratio; Copy CSS exports the current mapping and guards.

The three previews use Tailwind v4 utilities such as `bg-surface text-on-surface`.
`src/theme/tailwind.css` defines their shared public color contract; runtime values
come from the palette mapper. The iframe isolates template CSS, fonts, and icons.
`shared.css` contains only template layout and interaction rules, with defaults in
the base layer. Color transitions and opacity effects are omitted so intermediate
colors cannot break the checked foreground/background contrast.

### Download a Tailwind theme

After extracting a palette, use **Download Tailwind theme** before the preview
switch tabs. The downloaded `theme.css` contains an `@theme static` block with the
currently applied colors, including manual assignments and shuffles. Import it
into a Tailwind v4 project's stylesheet:

```css
@import "tailwindcss";
@import "./theme.css";
```

```html
<section class="bg-surface text-on-surface">
  <p class="text-on-surface-muted">Supporting text</p>
  <button class="bg-accent text-on-accent">Continue</button>
</section>
```

The theme extends existing colors without replacing fonts, spacing, or other
Tailwind defaults. Its 31 tokens cover canvas, surface, accent, secondary, tertiary,
paired readable/muted foregrounds, contextual accent foregrounds, and the original
text pigment (`border-pigment` for decoration). Pair foregrounds with their named
background; arbitrary combinations and opacity modifiers are not contrast checked.
The file contains resolved values and needs no Palette Masters code or assets.
`src/theme/export.ts` reads the same CSS contract used to compile the previews.

## Important limitations

1. **This ZIP does not yet bundle painting reproductions.** `npm run cache:art` needs successful HTTPS access to Wikimedia; verify file rights before distributing generated offline files.
2. **Preview restrictions:** A host-controlled CSP can block both Wikimedia API `fetch()` and `<img>` requests. Browser CORS and image-host CSP are different issues. A local Node server avoids ChatGPT's embed-specific policy but does not guarantee an external CDN is available.
3. **Search is not a complete catalog.** Wikidata and Commons are broad sources with uneven metadata, occasional mismatches and missing image rights; there is no consolidated master index.
4. **Color extraction needs image pixels.** Even if an image displays, Canvas access can fail for cross-origin images. The app keeps images visible and reports failure rather than inventing a palette.
5. **Art selection:** Five featured paintings/artists per movement are editorial starting points, not price rankings or objective historical importance scores.

For full details, continue with [PROJECT_HANDOFF.md](docs/PROJECT_HANDOFF.md) and [TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).

If port 8080 is already taken, see [the alternate-port instructions](docs/TROUBLESHOOTING.md#local-port-already-in-use).

## Color extraction methods

Six deterministic presets combine preprocessing, candidate generation and representative selection. They cover hue groups, Oklab K-means, octree, SLIC samples and medoids, with lightness, dominance or farthest-point selection. Hue groups, Oklab K-means and octree automatically compare two selection policies using theme usability and painting fidelity. SLIC + Original samples + Farthest, None + Medoids + Dominance, and Edge-weighted + Medoids + Farthest remain fixed presets. Additional algorithms remain available through advanced custom composition. See [the extraction guide](docs/COLOR_EXTRACTION.md) for exact combinations, selection policies and the painting-based pipeline story.

Implementation progress for composable, explainable extraction and dominance-based themes is tracked in [the pipeline plan](docs/EXTRACTION_PIPELINE_PLAN.md).

### Isolated template preview

The app loads `preview.html` in a same-origin iframe. Open `/preview.html` on the
local dev server to view the standalone renderer without app styles. Its entry
point is `src/templates/preview.ts`; template CSS, fonts, icons, resets, and artwork
presentation are loaded within that document. Responsive media queries use the
iframe width.

`src/templates/bridge.ts` retains the latest `PreviewState` (template, resolved
CSS tokens, image URL, artwork labels, and algorithm label). A ready handshake
sends it to the renderer, including after frame reloads. Both ends check message
origin and source. The renderer stays hidden until initial state is applied;
subsequent updates do not reload the frame or unchanged artwork. Image URLs may
be ordinary URLs, data URLs, or same-origin blob URLs; the creator must keep blob
URLs alive while displayed.

Browser fixtures can import `renderPreview` and supply a complete state directly
on `/preview.html`. Run the standalone/isolation checks with
`npm run test:browser -- tests/browser/template-isolation.spec.mjs`.
